Web News Aggregation & Visualization

An integrated news platform combining News API, Node.js/Express, MongoDB, FastAPI, Qwen-based AI event extraction, React and interactive data visualization.

Submission Deadline: 15 September
GitHub Repository

1. Introduction

The Web News Aggregation & Visualization project is designed to collect news articles, process and organize them through a backend system, enrich the articles using AI-based event extraction, store the structured information in MongoDB, and present it through an interactive web dashboard.

News Aggregation

News articles are collected using the News API and processed by the backend ingestion system.

AI Event Extraction

A Qwen language model is used to extract the primary event, category, location, summary and relevant tags.

Database

MongoDB stores the original article information together with the AI-generated structured information.

Visualization

The React-based frontend provides dashboards and graphical representations of the collected news data.

Project Objective

Core objective: Convert continuously collected, unstructured news articles into structured, searchable and visualizable information using an AI-assisted processing pipeline.

Instead of treating every article as only a title and block of text, the system enriches the article with semantic information generated by the AI module.

Data Flow

Step 1 — Collection

News articles are retrieved from the News API.

Step 2 — Ingestion

The Node.js backend receives and prepares the article data.

Step 3 — AI Processing

Article title and content are sent to the FastAPI AI service.

Step 4 — Extraction

Qwen generates structured event information.

Step 5 — Validation

The generated JSON is parsed and validated against the application schema.

Step 6 — Storage

The enriched article is stored in MongoDB.

Step 7 — Presentation

React retrieves the information through REST APIs.

Step 8 — Visualization

News information is presented through analytical visualizations.

AI / ML Core Logic

The AI module converts unstructured news text into a structured event representation.

Input

Article = Title + Content

AI Processing

AI(Article, Prompt) → Structured JSON

Output Representation

{
  "event": "Primary News Event",
  "category": "Technology",
  "location": "India",
  "summary": "Concise article summary",
  "tags": [
    "Artificial Intelligence",
    "Research",
    "Technology"
  ]
}

Conceptual Pipeline

Unstructured Text → Prompt Engineering → Qwen LLM → JSON Generation → Schema Validation → Structured Event

The system instructs the model to identify the single primary event and avoid inventing unsupported facts. The output is constrained to the application's expected structure.

AI Component Architecture

prompt.py

Defines the system instructions used to guide the language model toward consistent structured event extraction.

llm.py

Handles communication with the Qwen language model through the Groq-compatible OpenAI API interface.

schema.py

Defines the expected structure used to validate generated event information.

main.py

Provides the FastAPI interface through which the backend communicates with the AI service.

Backend Architecture
